用户要求先分析改进再开跑。本轮由AgentGain v3.2已发布提交dd0444f42延续，使用独立代码和运行目录，旧实验及预测不变。本页是方法与启动记录，不是已取得改善的结果。

## 针对上一轮问题的改变

| v3.2观察到的问题 | R4.1实现改变 | 可验证的作用与边界 |
|---|---|---|
| evidence.effect等辅助字段错误耗尽修复轮次，使显式答案丢失 | 回到原M式直接答/自主工具循环；只校验显式answer，reason可空，辅助字段不影响答案 | 消除这一类辅助字段导致的丢答；非法JSON、空答案和真正的错误答案仍会失败，不从reason猜答案 |
| 注入仅4/114、4/116、7/618 | 新生成task/specific源卡，任务卡通过任务和必要条件筛选后免除两词重合门槛；增加数量、形态、空间关系任务识别 | 可能提高可用覆盖；不保证医学适用性或正确性。specific卡保持原限制，不悄悄泛化旧卡 |
| 非注入题重新采样仍有差异，掩盖Skill归因 | 目标清单提前冻结，只在命中题生成两新臂；未命中题两臂均复用历史M | 未注入区没有重新采样净差；命中题仍为单次顺序运行，不能把每个变化视为确定因果 |
| 实际工具使用极少 | 恢复M式自主选工具和直接作答，最多6主模型/4工具 | 无强制工具，也无投票，不能保证调用更多或带来纠错；必须报告实际使用 |

新两臂为M-S41（有任务行动卡）与M-C41（无卡），同模型、工具菜单及6+4上限。M-S41的system说明允许源行动卡，M-C41保留无跨病例Skill说明，这是实际处理条件的一部分。历史M只是复用参照，与新策略比较混合实现、预算和时段差异。

## 源准备、审阅与冻结

使用已隔离69例、260条已释放源轨迹、137份明确标签原图生成新R4.1候选，最多每例一次源请求，不把旧v3.2回复冒充新输出。必要病史/成像前提不得为提高覆盖而删除。每张候选结合源原图和源轨迹明确接受或拒绝，保留理由和候选hash；任务卡至少一张审核通过才能冻结。此为操作方辅助审核，不声称全自动或独立临床认证。隔离范围沿用已披露解码像素和可用ID检查，不声称排除所有近重复。

冻结目标mask只读问题、完整选项与图像数量；不读目标参考答案，不按中途成绩改卡或阈值。最多一张卡、最多2200字符。先检查各子集覆盖，尤其OpenI；没有覆盖的子集不能评估Skill效果，总覆盖0不执行付费目标。不会为追求覆盖数字强塞不适用卡。任务识别是规则启发式，必要语境仍依赖审核后的前提和模型判断，不能视作临床适用性认证。
