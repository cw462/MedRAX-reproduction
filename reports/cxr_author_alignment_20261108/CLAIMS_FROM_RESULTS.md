## what_results_support

1. **完整结果可核对。** `results/per_question.jsonl` 有 11,848 个方法—题目记录、45 个数据集—方法组，其中 41 组为完整队列、4 组为部分联合问答队列。直接按组累计的题数、旧严格正确数、新正确数、未提取数、答案域失败数和技术停止数全部与 `summary.json` 一致，未见组内重复题号。D-Q/M-Q 在各自队列中的题号集合一致。注册表涉及的 20 个历史目录中，现有 inputs/references 文件的题目、选项、image_id 和答案字段与本次规范队列一致，未发现冲突。

2. **新评分器保存了评测边界。** 所有方法先完成不带参考的提取，之后才打开参考文件；答案对错由独立的 `outcomes` 计算。没有从 reason、医学常识或参考中补答，也没有按对错选择重用来源。完整臂检查完整题号集合；末次实际请求按数值 ordinal 选择；无新请求沿固定整臂链回溯。技术停止、原生工具计划和显式尚未执行的 JSON 工具计划按冻结协议保守计未完成。全体结果中，未提取、冲突、技术停止和非最终工具计划获得主成绩信用的数量均为 0；真实缺失获得 legacy seeded 信用的数量也是 0。对现有评分代码及实际结果的检查未发现使比较失效的实现错误。

3. **作者指标与工程格式分开了。** M4CXR 的特殊 token 清除、首尾空白处理、去句点、转小写、完整答案 EM 与参考词集合 recall，在本地固定作者实现中有依据。本次没有添加 true→yes 等别名。CheX 的选项映射是项目共同适配器，使用题目给定字母或完整匹配选项，不声称是每一个作者脚本原样执行。whole-JSON 和原 M 两键/300 字符约束只作诊断，不再作为主答案正确性的前置条件。词 recall 是辅助指标，不能替代 accuracy。

4. **直接模型和全部登记方案的描述性成绩有支持。** D 在 CheXbench、SLAKE、VQA-RAD 上分别为 411/618、104/114、85/116；原 M 为 455/618、106/114、99/116。完整臂中，CheXbench 最佳为 M43：466/618，micro 75.4045%，三子集等权 macro 77.0773%；SLAKE 的 M-R、M-S41、M43 均为 108/114（94.7368%）；VQA-RAD 最佳为 M42：100/116（86.2069%）。这些是固定旧档在所声明共同指标下的排名，不能解释成同预算、同信息条件的独立 Agent 因果效应。历史资源记录已经显示 D 与多种 Agent 的调用和 token 数不同；相同 qwen3.7-plus 主模型标识不足以消除预算、工具信息和开发轮次差异。

5. **统一口径改变了 R43 增量的解释。** M43 对固定前驱 M-C41 的 CheXbench 比较是 461→466，5 个纠正、0 个误改；对 SLAKE M-S41 是 108→108，0 个纠正、0 个误改。VQA-RAD M42 对原 M 仍为 99→100，1 个纠正、0 个误改。CheXbench 新微平均差为 +0.8091 个百分点，保存的图像簇 bootstrap 95% 区间为 [0.1621, 1.5974]；宏平均差为 +0.4386 个百分点，区间 [0.0882, 0.8636]。SLAKE 差为 0；VQA-RAD +0.8621 个百分点，区间包含 0。这些区间仅描述当前开发样本，不能消除反复开发和挑选整臂的影响。

6. **格式/接口损失得到量化。** O 从旧严格 47/618、21/114、7/116 变为 448/618、103/114、89/116；D-Q 从旧严格 0 变为 160/204、105/114、73/94。原始预测没有因本次分析而获得新信息；这些差异证明旧评测接口曾遮蔽大量已经生成的显式答案，不能称为本次分析训练出了新能力。CheX204、VQA94 的 D-Q/M-Q 只能单列或作相同题号子集比较；不能将其百分比排名放在 618/116 完整队列中。

7. **Skill/记忆效果并不一致。** M-S 相对原 M 的微平均正确数差为 CheX −2、SLAKE −1、VQA −7；M-E 为 −30、−2、−7。M-S41 相对 M-C41 为 −8、+2、−2。v32 M-AS 相对 M-A 为 +10、−1、+5。CheX 的 M-S 虽微平均低于原 M，等权宏平均却略高，正说明结论必须指明指标和子集；不能笼统写“Skill 有效”或“记忆无效”。

## what_results_dont_support

- 不支持“整条回复恰好 answer/reason 两键、answer≤300 字符是论文统一要求”。这些是项目工程约定。也不支持将当前整合适配器命名为“未经修改的官方评分器”。已审阅的作者实现之间存在输出接口与解析规则差异；CXRAgent 的精确 benchmark 解析器仍未知。
- 不支持把本次重评分带来的涨分当作新模型准确性提升，更不能称为新医学知识、临床诊断改进或官方 SOTA。此次为零新增模型预测的分析，R42/R43 的先前请求才是历史上真实发生的生成步骤。
- 即使统一指标下 R43 还净增 5 题，也不能把五题全部称作新增医学推理。实际变化包含冲突答案消解、未完成工具计划定稿，以及旧答案 `Left side`、`No`、`No cardiomegaly` 变为可匹配的选项字母。分数变化本身不能区分视觉推理改变与答案域完成。
- 不支持以 CheXagent legacy seed-0 分数说明模型能力。当前显式答案大多没有括号字母，该敏感性在相应记录上主要由随机回退贡献。其输入是共同适配后的显式答案，旧提示和原论文种子也不相同，因此不是准确复现原论文；无括号解析、随机触发和随机信用必须继续分列。
- 不支持将不同预算/工具信息/开发轮次的历史臂差值解释为 isolated Agent benefit，也不支持“所有 Agent 在每个子集均优于 D”。完整表格应允许负差值、并列和子集异质性直接出现。
- 不支持未见样本泛化、反复开发后的统计确认、机制安全性或普通临床效益。SLAKE114 的题数相同不证明论文题号相同；VQA-RAD116 为明确筛选的胸片闭合题扩展。CheXbench 的 SLAKE 子集与独立 SLAKE 可能重叠，不应汇总成独立总样本或总准确率。
