## 为什么与截图里的旧数字不同

论文及作者代码的答案指标与本项目额外输出结构要求已分开核对。所有历史方法都用同一个参考无关显式答案适配器，按CheX给定选项做明确映射、独立SLAKE做M4CXR式答案EM/词recall；VQA116的该指标是明确声明的延伸。多个矛盾答案、无终态、未知发送、工具失败和未完成工具计划保留为缺失，不从reason或参考猜答。额外字段、缺reason、JSON围栏、旧300字符上限不再自动否定明确的答案。

此主表名为**作者指标＋共同显式答案适配**；不是未经修改的统一官方解析器。CheXagent括号字母/随机回退、MedRAX A/B前缀与ChestAgentBench定稿追问分开说明，CXRAgent未确认的具体解析仍标未知。仅有相同SLAKE114题数不代表已经拿到论文完全相同题号。详见[出处审计](../cxr_task_completion_r43_20261108/EVALUATION_CONTRACT.md)、[事前协议](PROTOCOL.json)。

旧预测、旧状态、旧成绩均不变；每个旧正确数都与原已发布缓存摘要一致。旧D/M/M-C41的CheX410/452/458统一后为411/455/461，M43仍466。[各自旧协议总表](LEGACY_STRICT_TABLE.md)可对照截图。

R43对其固定前驱在统一指标下是**CheX+5、SLAKE0**；VQA M42对原M仍+1。五个CheX差异仍包括矛盾消解、未完成计划定稿和答案域完成，不统一称作新增医学推理。O的旧47/21/7恢复到448/103/89，D-Q的旧0恢复到160/204、105/114、73/94，揭示的是旧输出接口损失，绝非本次产生新模型能力。[全部适配影响](ADAPTER_EFFECTS.md)。

## 下一步真实纠错方向，尚未启动新付费实验

1. **任务条件分流。** X在Rad-Restruct82而M4373，M43在OpenI276而X220，优点不同；先在源/开发上用题型/可观察输入验证固定策略，不能根据目标参考逐题挑法。
2. **短Skill的适用条件。** R4.1 Skill对无卡对照统一净差为CheX−8、SLAKE+2、VQA−2；先比较一个有源证据、边界明确的短Skill与同预算无卡对照，不能盲目扩库或宣称记忆整体有效。
3. **不适用工具/记忆证据的纳入门槛。** 源病例经验对M为−30/−2/−7；优先检查是否注入不适用证据，在独立源/开发最小配对中固定工具/调用预算和信息条件，随后再决定目标范围。

下一独立最小方案需写明源/开发划分、候选机制、同预算对照、输出及答案指标、调用规模和授权范围；不复跑R41/R42/R43，不把已反复开发的benchmark当未见测试。当前交付的是已完成表格和解释，真实准确率继续优化目标仍未声称全部完成。
