# R45实际记忆与带真值情景记忆E的区别

R45的可用记忆包含：已处理同图题的题干、选项、模型答案、模型理由、状态及健康工具文本。首次题来自固定历史M43，后续已完成题来自本轮预测。没有真实参考答案、正确性反馈、基于真值的retrospective summary或可执行guideline；没有跨病例相似度Top-K检索。它是同图顺序上下文实验，不是完整的带标签跨病例episodic memory E。

参考答案另存用于事后评分：生成完成后，先对全部实际模型终态进行参考无关适配，再读取参考；未回写到运行时记忆。130道后续题实际获得记忆，488道首次／单例复用历史M43；详见[冻结协议](PROTOCOL.json)和[逐题上下文](CASE_INDEX.md)。

用户列出的E可包含模型答案ŷ、真实答案y、工具轨迹、retrospective summary与guideline。独立训练／源病例的合法真值可用于构库；需要病例／图像层面的来源隔离，不能根据目标题参考选择检索例子。若向后续评测题反馈同一评测病例的真实答案，则属于另一个带反馈的在线／顺序评测条件，不能沿用独立单题或未见测试主张。是否包含真值由实验设定和信息来源决定，并非所有记忆都必须排除真值。

用户已授权下一轮，并随后核对该区别。目前新实验仍在方案准备、尚无新增实验推理请求；联合回答与源病例带真值的E是不同机制，方向已明确改为源病例带真值的E：逐题先预测、后揭示源真值并反思入库；源流结束冻结E，开发评测不回写真值。另冻协议和预算。R45记录及465/618结果保持原样。
