## 配置、资源与运行局限

主模型 qwen3.7-plus，temperature=0.2，top_p=0.95，关闭 thinking，最大输出 2048 tokens。M−R 每题最多 4 次主模型调用、2 次可选工具。O 使用冻结官方 MedRAX 工作流，提交 dae30e2f136ef0b2a40885a4c335386e9ffad052、LangGraph 0.2.76 默认递归上界 25，对应最多 13 次主模型调用，无额外可选工具上限，RoentGen 关闭。O 的 116 题均在官方图终点结束，非递归上限截断。M−R 有 1 条无效工具计划、1 条无效最终 JSON；均保留并计入完整分母。

运行曾因共享账本读取异常停等，后按用户指示移除共享账本执行依赖并取消金额上限，使用各请求发送标记、原始回复和返回用量记录费用。历史账本、已有预测及工具观察保留。恢复复用了已保存回复，未知已发请求未重发。专家工具由被其他进程占用的 GPU 1 路由至 GPU 0。O、M−R 各有 8 条失败后端记录，失败、缓存复用和后续合法错误答案分开计数；不把技术恢复视为纠正模型错误。这些运行差异与单次随机采样限制了对算法单因素的因果解释。
