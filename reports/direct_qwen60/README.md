# D0 无工具直接作答对照（运行前记录）

本轮新增 qwen3-vl-plus 直接多图作答：固定原60题，每题独立会话，一次请求，输出选项和短依据。模型、采样、2048输出上限、图像字节/顺序/图号/detail与V12首次输入对齐；不初始化Agent、工具或检索器。D1关闭。

[用户确认的方案](design-plan.txt)；[固定配置](../../configs/direct_qwen60.json)；[运行入口](../../experiments/run_direct_vlm.py)；[后置评分与导出](../../experiments/compare_direct_vlm.py)。旧结果固定于5594a29e8a9ad7c253b50addb9fef23998909e7e，仅作缓存对照。

正常60次新请求；瞬时技术故障每题最多额外1次，全组额外最多6次，总额度66次贯穿断点恢复。成功响应不因答案或格式重试。原始回复在解析/结算前保存；恢复复用已保存回复，未知的中断请求不盲目重发。前两题计入正式实验，保存正常后自动继续。

继承同一费用账本、既有cap、身份、锁、金额和保守恢复规则。沿用用户授权的V12ProviderLedger，运行时_check_disk仅调用_check_open，取消原始字节一致性停机；没有新增替代扫描。只在准备/恢复时对固定输入配置进行一致性核对。

生成器只接受question_id、question、images输入，读取V12 selection时也仅映射这三字段，不读取旧答案或参考标签。全部60个终态完成后，独立比较进程读取已评分公开缓存中的reference，按完整60题分母评分，单列四项转换、候选/求解器/控制器回退，以及调用费用和耗时。该60题为反复使用的开发集。

实际执行提交保存在protocol.json的implementation_commit；本页是运行前记录，不表示实验已完成。
