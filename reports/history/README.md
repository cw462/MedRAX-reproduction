这里不是一条可直接解释为“模型能力随版本变化”的曲线：各轮输入范围、提示、工具、预算和 P0 生成时间不同。**只有 V11 明确复用了 V10 的冻结 P0/VKE，避免重跑基线。** 其余跨轮变化只能作历史描述，因果判断应看当轮同题对照。

V8 是知识资产及方案版本，本包不为它虚构独立准确率结果。计划中的 R4–R7、重复轮次、B 长度控制、外部/heldout 评估等，必须以实际目录与完成记录判断是否运行；不能因为计划列了名字就算完成。

## 本次补查需要订正的历史说法

- **V7 分母和缺答：** P0 42/60，P1 28/60，PB 39/60，PC/GC 40/60，GB 42/60。旧表中的 51.85% 是 P1 28/54 的合法回答条件准确率，不是固定 60 题成绩；原 JSON 的 `over_planned` 字段已按 60 计算，但旧 Markdown 主表及成败分解没有清楚区分。P1 的 2 次纠正、12 次合法误改之外，还有 4 次原本正确变成缺答，所以总净损失为 14。PC/GC 没有合法误改，但各有 2 次正确→缺答。详见[固定分母明细](early/v7-fixed-denominator.json)。
- **八工具前后比较：** 预算释放同时发生了返回契约修复；数据不支持旧报告中“完全是四次调用上限造成”的单因素归因。
- **固定 60 题并非完全没有开发曝光：** `13238_8353800603808` 在早期 `val30_r0_v1` 已有 2 次模型调用后超时，另两次旧 R1 运行各有 2 次调用后费用保护退出。没有获得合法答案，不等于没有输入曝光。旧文件“从未用于开发”的绝对表述不成立。这是已找到的至少一题；不据此宣称已穷尽所有历史暴露。
- **统计结论边界：** 旧 V4 文本把宽置信区间写成“排除大于某数值的收益”，容易过强；单轮、小样本、部分配对排除失败，不能证明方法无效或建立稳定上界。历史结果不是独立测试主表。
- **公开范围已经扩展：** 旧报告的“病例、工具正文仅保留私有目录”是先前发布范围。此次用户明确要求上传病例与图像，V9/V10/V11 的原始可观测过程现已补齐。

## 完整性与仍无法恢复的内容

“补齐”指把现在仍有的历史原始记录完整归档，**不能找回当时没有保存的内容**。早期部分运行只有终态、工具参数摘要、输出摘要或哈希，没有原始 assistant 消息和工具全文。对应缺口已在[早期报告](early-experiments.md)逐项标明；V9 的 9 个规划前失败分支没有生成规划/检索文件，也明确保留为缺失。

V9/V10/V11 的公开消息是实际保存的可观测请求/响应；没有要求或编造隐藏思维过程。图像 Base64 改为指向同字节图片的链接，运行机器私有路径和无关账户元数据移除。保存的旧摘要值只是来源标识，不是脱敏文件的新校验结果。

所有参考答案、评分、正确/错误分组均在生成结束后用于本次复盘。现已公开的病例包不可再作为答案盲态输入。病例与影像源自公开 ChestAgentBench/Eurorad，保留来源和适用边界；第三方材料不被仓库代码许可证重新授权。模型权重、凭据、无关文件和临床文献全文不包含在本次发布中。
