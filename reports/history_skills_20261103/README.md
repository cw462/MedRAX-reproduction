## 临床历史与预先标记

从官方 eurorad_metadata 仅提取 age、gender、history，放在当前题之前的 Clinical history 块。按 case_id 关联，保留原文与来源；缺失为空且记录，不编造。PDF 的“全部有历史、长度统计”是输入前提，实际覆盖在准备时单次记录。

严禁向回答请求传入 title、diagnosis、differential_diagnosis、image_finding、discussion 或参考答案。检查实际最终请求的字段允许清单；不是只靠提示要求模型忽略这些字段。

运行前生成历史风险清单，之后不根据分数调整：

1. case-insensitive 匹配 radiograph/radiographic、X-ray/xray、CT、computed tomography、MRI、ultrasound、opacity/opacities、mass、effusion、nodule、shadow、consolidation、infiltrate、pneumothorax 等预定义词/词形。
2. 英文词按字母切词并 casefold；长度至少 4，去除固定停用词后，若 history 与 diagnosis 共享词则标记。诊断仅由隔离的标记准备程序读取，输出只有 case_id、风险布尔值与规则代码，不输出诊断或共享词，不进入 worker/技能检索。
3. 发布每病例标记、规则、覆盖统计与一次性 SHA256；历史标记不能由参考答案正确性、模型结果或事后阅读失败题决定。该规则是保守风险分层，不保证未标记历史绝无影像信息。

H1/H2/HS 同时报告全体 402 题与未标记子集。历史配置只有全体及未标记子集相对其基线的病例级增益区间下界均 >0 才可称为支持历史增益；未标记子集为空或不足两病例则不作通过判断。HS 另报告相对 S1 的差值，判断加入历史的增量，不能把 HS 对 F 的全部提升都算作历史作用。

## 技能学习、跨折与冻结

分折已按 seed=20261103 固定为 A 50 病例、B 49 病例；同病例所有问题在一折，遵循源题目顺序。反思抽样使用 seed=20261104：F 的 82 道错题全部纳入，320 道对题中无放回抽 floor(320/3)=106 道，共 **188 次反思请求**。这修正文档“约120次”的算术估计。

- 反思使用 Flash，输入该源折题目的原图、题干、F 实际答案/理由与参考，每题最多两条 trigger＋image-check steps。只允许这个训练进程读取源折参考；回答 worker 不读参考。
- 每条技能保留来源折/来源题号用于审计，但提供给回答模型的正文不得含病例 ID、选项字母、图号、患者特有年龄/日期/数值、仅复述参考诊断而没有通用检查步骤的条目或题目原文拷贝。过滤/合并为确定性本地步骤，不为合并另起未预算的 LLM 请求；每折最多40条。
- A 的题仅检索 B 的技能，B 的题仅检索 A 的技能。S1 与 HS 使用同一个预先冻结的跨折库及检索规则，不能先用 S1 的目标折成绩剪枝再答该折 HS。
- 检索只用当前问题和官方类别，不用选项正确性、历史诊断或兄弟题：同类别 trigger/steps 采用固定词项 TF-IDF cosine，取前三；general 取前二，稳定 skill_id 排序裁决并列。没有匹配则少取，不补充其他病例内容。官方类别的使用需公开披露。
- PDF 的“最有用 general 技能”在首次跨折回答前没有独立效用数据，故本轮首次跨折只用预冻结匹配排序，初始效用相同，禁止用目标折反馈预选。这一实现差异必须在报告披露。
- 全部 S1/HS 回答完整保存后才评分。效用按 S1 中“实际检索该技能”的问题上纠正减误改计算；同题多个技能均记关联，不能称为因果信用。未检索技能效用记 null，冻结时排除；负效用剔除，零效用保留。
- 两折存活技能本地合并，最多60条；按效用降序、稳定 ID 处理并列。最终库、检索参数、提示及选择结果在保留集前记录一次 SHA256。最终 general 可按已保存跨折效用排序。

跨折调参成绩使用未受目标折反馈修剪的库；最终合并库是之后的新冻结产物。二者分布不同，须由保留集确认，不能重算调参成绩美化收益。HS 的技能效用仍只来自 S1，避免根据 HS 表现另选库。

## 门槛与唯一配置选择

主候选 H1/S1/HS 与 F 比较；H2 单独与 D 比较，不用 Plus 相对 D 的增量与 Flash 候选混排。采用2,000次病例级配对百分位 bootstrap、seed=20261103、题数加权差值，区间下界严格 >0；“约+2.5pp”不是固定题数门槛。

H1/HS 还需通过上述未标记历史子集条件。通过候选按对 F 的准确率增量降序选唯一赢家；净增相同时优先 H1，再 S1，再 HS。若无候选通过，使用 F。不按类别为每题择优，不调整投票权重，不根据保留集结果重新选择。

只有所有调参臂、反思和控制完整结束后才运行独立评分与配置选择；反思使用的训练参考是明确例外，不是提前读取候选成绩。历史风险准备读诊断的例外另列。保留集/其余全量题参考均不进入这些步骤。

## 六阶段顺序与数据复用

1. 用户确认后，准备并冻结输入清单、历史标记、折/反思列表、完整提示、检索及输出合同。之后运行 H1/H2、反思→跨折 S1/HS、C1–C3；都完整后统一评分。
2. 按门槛选择唯一配置；冻结最终技能库（如使用）、提示、历史输入政策及其余参数。
3. 保留集1002题：F、赢家独立回答、赢家病例串行三个配置各一次；赢家=F时复用同一个独立结果，不重复调用。D 使用已有793/1002结果。
4. 所有保留集预测保存完整后隔离评分；其结果不改变赢家、库或任何全量参数。
5. 全2500题：F 和同一赢家逐题独立。按 question_id、图像/输入配置、模型参数、技能库版本判断语义等价的已有结果并相对引用，不重发；同题不同库或上下文不能复用为同一配置。F 可复用原402+本轮1002；H1可复用同配置调参和保留集；S1/HS的402跨折答案不冒充最终合并库答案。
6. 所有预测完整后统一全量评分与最终公开报告。全2500包含已用于学习/选择的402调参题和1002保留题，报告拆分这些部分及其余1096题；整体2500不能称独立测试集，也不再据此选方法。

执行前需要用官方题目 ID 单次建立2500题清单，确认402与1002子集关系及病例归属；若并非文档假设的包含关系，先保留现有结果并修正复用清单和请求上限，不能悄悄换分母。未见病例还需披露是否与调参病例重叠。全量实际输入当前尚未准备。

病例串行是原 E2 Sequential 实现的协议对照，不声称等价运行了官方 MedRAX 工具代理。按病例内位置报告题级准确率，首题单列；病例题目全对比例另列，不能与“病例对话中的题级准确率”混用。

Batch 使用已有 Plus354/402、C1等控制结果作为已测信息共享参照；并非数学上界。文档“每配置三个数字”仅在有对应实测臂时填写，缺测记 NA。本预算没有为所有配置新增批量、所有模型的全量D或全量串行臂，不伪造缺失单元格。
