# Run-specific source

These files are the exact eight-tool Python sources stored in the sealed DATA archive. The AutoDL package also referenced a native R55 tool environment and the frozen dataset manifests. Use the release provenance and source locators to obtain those dependencies.

From a deployed AutoDL study directory, the original controller command was `python -B -u data8_optimization_runtime.py run --arm ARM`, where `ARM` is DATA, GEPA, META, or GEPA_META.
