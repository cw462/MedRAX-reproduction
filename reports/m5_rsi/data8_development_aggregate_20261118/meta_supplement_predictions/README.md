# META 邻居加权补充实验逐题结果

[逐题 CSV](predictions.csv)含三组策略各 300 道开发训练题和 100 道开发验证题，保存冻结题号、预测、参考答案、得分和调用次数。[配置与分数](../META_SUPPLEMENTS.md)说明三组固定策略的差异。验证题沿用[原开发集逐题来源](../details/SOURCES.md)。

在相同的 100 道验证题上，以 +0.5 邻居加权作为对照，配对变化如下。

| 策略 | 由错变对 | 由对变错 | 净变化 |
| --- | ---: | ---: | ---: |
| `META_NEIGHBOR_02` | 3 | 1 | +2 |
| `META_NEIGHBOR_05_FILTER` | 3 | 1 | +2 |

[配对变化题号](paired_changes.json)记录每组更正和回退的题目。
