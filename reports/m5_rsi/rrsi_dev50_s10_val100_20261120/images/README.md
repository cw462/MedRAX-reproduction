# 图像与来源

`slake/` 包含 176 份本次记录引用的 SLAKE 图像：63 份原图、113 份工具派生图，分别按 M5 和 S10 保留；相同图像在不同运行中的副本分别记录。图像均保持收集时的字节内容，裁剪和工具标记属于实际运行产生的派生结果。

SLAKE 的作者为 Bo Liu、Li-Ming Zhan、Li Xu、Xiao-Ming Wu。来源为[官方项目](https://www.med-vqa.com/slake/)及[作者发布的数据](https://huggingface.co/datasets/BoKelvin/SLAKE)。作者数据卡列明 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。[逐图署名与派生关系](slake_attribution.json)保留来源标识、题号和原图关系。

[完整图像索引](index.json)将原图、工具派生图、运行和题目关联。记录中的 `images/slake/...` 路径均相对于本报告根目录。OpenI/Indiana University 图像及对应派生文件以来源引用保留；本报告没有统一的逐图转载许可依据，未将其二进制纳入附件。
