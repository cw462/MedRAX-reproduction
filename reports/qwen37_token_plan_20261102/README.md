## 预算、故障和时间

原新增预算授权 **¥200 不增加**。前轮已耗记账代理 **¥3.163412**，本轮继承后剩余代理预算 **¥196.836588**；不会重置为另一个 ¥200。正常请求 4,484，技术额外最多 230，总硬上限 **4,714**。

Token Plan 的实际用量单位是服务商 Credits。目前没有可核实的固定 Credits→人民币换算。输入/输出每百万 tokens 的 **4/12 CNY 仅沿用原记账代理**，不是 Token Plan 实际费率、收费上界或账单。保守预留与返回 usage 估算的差额会披露；运行器不自动购买额度。私有账户总额和账本不发布。

样本级确定拒绝可按既定规则记缺答后继续；未知结果不重发；鉴权、模型身份、额度、账本保护错误立即停止。仅非额度 429 可在既有次数上限内重试一次。所有已有终态保留，不为格式或低分追加付费请求。

按首批请求速度，总耗时初估 **3–5 小时**，即北京时间 11 月 3 日约 **02:45–04:45**。这是早期吞吐量外推；后续多图、高分辨率输入、限流或故障可能延长。
