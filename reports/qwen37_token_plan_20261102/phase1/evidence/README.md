Each request image URL is replaced by a path relative to that request file. The adjacent image metadata, figure label, source filename and request order remain bound to the saved pixels. Request parameters, response content, reasoning content and observable stream chunks are retained; private credentials, account balances and local absolute paths are removed. This exporter does not load reference labels or account ledgers and does not generate predictions.
