仅为此增加显式“尚未发出请求”的恢复入口：核对当前停止阶段/组、fatal 与 reserve_error 的题号及样本号和错误一致；要求没有请求启动、响应、结果、终态或终态停止事件。通过后写独立恢复确认，交由现有阶段运行器继续尚未完成样本。原账本构造接口仍须通过原校验才能发出 API；不改身份、锁、金额或 checksum 保护，不重置计数，不重发结果未知请求。

原候选校验为何不一致仍未查清。已读取服务器上对应摘要和提交函数，未发现不同实现；不能据此认定磁盘损坏、字节漂移或硬件故障。没有另做全账本或哈希扫描，也没有再单独反复重开账本。旧错误、未发送请求材料和状态均归档。实际恢复状态与修订提交见 [incident.json](incident.json)。
