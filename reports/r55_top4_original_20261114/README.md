## 协议与运行

每个方法对三个数据集分别从空记忆起跑，保存预测后释放当前题反馈。主答为 qwen3.7-plus，记忆模型调用为 deepseek-flash，R54 Skill 生命周期关闭。工具有 CheXagent、LLaVA-Med、MedGemma、LLaVA-Rad、MedVLM-R1、MAIRA-2 报告和短语定位、ROI 裁剪、MedRet、Reflect、Verify。CheXBench 用选项正确率，两个开放短答集用此前的显式答案规范化与匹配。原始数据评分器和工具适配源码随包存档。[详细协议及正式分数](summary.json) · [代码](source)
