## 适配与输入记录的限制

1. **源折反思上下文不足**：适配器创建Trajectory.query，但固定官方编码器实际发送的是steps；本轮steps未显式加完整题干与选项，错误题参考只给字母。例如[源折分析请求](../calls/eAw0q16560_8353800455556__1/checkpoints/16560_8353800455556/sample_1/request.json)含“Correct Answer: B”而没有完整原题。因此反思的语义纠错信息有限，可能影响技能质量。没有事后补提示、重学或重跑来选择更高分结果。

4. **统计边界**：402题/99病例已用于多轮开发，非独立保留集；区间条件于本轮固定预测，不含技能训练随机性。旧S1/HS流程不同；无匹配工具Agent对照，无法得到纯记忆效应。
