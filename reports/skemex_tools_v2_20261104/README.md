## 四项修改

1. **反思实际请求含完整纠错上下文。** 同病例所有源预测保存后才打开该病例参考。构建一个明确标为“源折监督反馈”的步骤，其 `action_input` 包含完整题干、全部选项、旧字母及对应原选项文本、旧回复、正确字母及对应原选项文本、图像绑定、实际使用的工具观察和完整原始工具返回。官方编码器实际序列化这个字段且不按 observation 的长度截断；不再只依赖 `Trajectory.query`。原始轨迹与这份源折反馈分别保存。反思仍是文本，不伪称模型重新看到了影像。官方分析、审查、效用和维护代码不改。

2. **重建技能，并约束工具能力。** 分类器只用于已确认胸片；发现分数不能当校准概率、严重程度量尺或纵向变化分数，也不能应用于CT/MRI。无高分不等于正常。规划允许0–2次工具调用，即便有胸片也可拒绝无关工具。反思提示明确这些限制；适配器对已识别的“分类分数=严重程度”“胸片分类器用于CT”“影像必须调用工具”表述增加窄范围拒绝规则，覆盖新建和补丁；维护合并后的活跃库在再次检索前检查，出现明确违规便保留现场停止。官方质量审查不放宽。**这些关键词规则不是医学语义验证器，不能保证捕获所有错误概括。**

3. **隔离单图报告的时序断言。** 原工具报告不改写。供 Agent 使用的投影按句/分号/换行分段，含 interval、improvement、increase、decrease、prior、unchanged 等预先固定词根的片段整体不作为输入证据，并记录被隔离的片段数量；原文可从原始调用记录核查。剩余静态描述仍标为未验证，可能矛盾或幻觉。比较题必须依据题目明确绑定时点的原图；图像顺序、文件名或单图报告不能建立先后关系。时点未绑定时明确保留不确定性。词根规则会误删部分静态信息，也可能漏掉时序改写；它与原图核查指令共同构成修订，不宣称彻底消除时序错误。

4. **最终选项绑定。** 使用单个JSON输出 `answer`、`option_text`、`reason`；`option_text` 必须逐字等于该字母的完整原选项。模型提交前须检查理由与选项一致。解析器只接受合法字母与精确文本匹配；格式错误或不匹配保留原回复、记为缺答，固定402分母，不额外付费修正或从理由改写答案。字符串匹配不能证明理由与选项医学含义一致，这仍需逐题报告。

以上四项是一组修订。不能仅把前后差异解释为检索、技能或某一工具的独立收益。
