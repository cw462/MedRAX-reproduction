# V11 完整复盘：结果、病例、图像与裁决记录

V11 S1、S2、S3 均已完成并独立评分。**39/60 的 P0 经 S1、S2、S3 后分别为 38、41、40/60；最低开发目标 42/60 未达到。** 本次发布保留原实验结果，提供足以逐题复核的输入与证据；未重跑推理、未修改终态记录。

用户于 2026-10-31 明确要求每次实验结束后自动发布详细复盘，并将发布范围扩展到病例题干、完整选项和相关图像。这里收录本次实际使用的公开基准子集及派生材料，不包含凭据或模型权重。

## 建议阅读顺序

1. [失败分析](failure-analysis-2026-10-31.md)：哪些失败已被证实，哪些仍是待检验假设；收益为何被误改抵消。
2. [裁决记录实证分析](decision-pattern-analysis.md)：模型回答与解析结果的差异、具体 JSON 解析缺陷、逐题观察矛盾与边界。
3. [60 题结果表](per-question-outcomes.json)：P0、候选、S0–S3、评分、路由、补充观察标志、资源；参考选项在全部生成和评分完成后，从原独立评分标签输入补齐，60/60，仅供事后复盘。
4. [60 题图文导航](cases/README.md)与[病例/图像机器清单](cases.json)：完整题干/选项、实际原图和局部图像、工具观察、单题可读页面入口。
5. [裁决明细](decision-audit.json)：逐题解析信息、观察摘要及受影响回答原文；模型声称的观察不是人工临床标注。
6. [机器可读汇总](summary.json)与[来源说明](data-provenance.md)。
7. **2026-10-31 补全：**[完整调用与终态记录](traces/README.md)收录 S1/S2/S3 的 180 份逐题归档，对应 563 个已保存 JSON checkpoint，包含实际提示、原始 assistant 回复、工具/图像引用、解析字段、上下文用量和补证记录；[跨版本历史索引](../history/README.md)串联早期、V9、V10 和本轮。

通过 `question_id` 联结上述文件。模型看到的 X/Y 身份隐藏只适用于当时的推理；本次完成后的复盘公开其对应关系，以便定位错误。原图、工具输出和模型观察分别保留，不能把工具或模型生成的描述直接当成事实。查看图片时还应核对局部图像的父图、坐标、原图顺序与方向。

本次病例包包括 **117 张不重复原图、21 张已有局部/工具图、9 张 S2 裁剪图**，共 147 张，约 12.56 MB；21 道分歧题带有 140 条缓存工具观察、各轮裁决与盲读记录。病例页展示的是当时实际输入与保存的输出，并未为解释失误重新生成图像或回答。

供 GPT 复核时，可按以下要求阅读：先定位错误题的参考选项与所有完整选项，再看对应原图、图号及局部坐标；分别列出工具、独立读图和裁决器的原始断言，核对是否存在尺度、侧别、数量、时间先后的证据缺口；每个结论注明 `question_id`、图像 ID 和观察引用。把可见事实、模型推断、标签结果和待核实解释分开，不根据参考答案编造图像证据。
