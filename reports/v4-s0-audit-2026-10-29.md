## Defects found by actually running it, and fixed

1. **A run directory that exists but is unfinished aborted the whole stage.** The second
   launcher died with `FileExistsError` from the eval's journal because the previous
   attempt had left `runs/v4_B_r1`. Worse, `--resume` tested only for `summary.json`,
   which the journal writes after *every* question, so a killed run looked finished.
   Fix: a run counts as finished only when `stop_reason == "complete"` and the planned
   question count is covered; an unfinished directory is moved aside
   (`<name>.stale-<utc>`), never deleted.
2. **A relative input path cannot work.** `run_arm.sh` cds into `code/`, so
   `--input runs/...` was resolved from the wrong directory and the first S2 launch died
   with `FileNotFoundError`. Fix: the orchestrator resolves the input to an absolute path.
3. **S2 must not reuse S0's run names**, or `--resume` would skip S2 outright. Fix:
   `--tag` inserts a stage prefix (`v4_s2_A_r1`), and `--input` selects the fixed
   60-question file. These are in `run_skill_validation.py` and unit-tested through the
   `_run_complete` helper.
