# V9 completed diagnostic: public results index

本目录用于回溯 2026-10-30 的固定 20 题实验。实验于北京时间 14:15:12 开始，15:24:43 完成，约 69.5 分钟；20 个 P0 和 80 个分支均有终态记录。本次是开发诊断，不是独立测试集评价。

## 结果与解释

| 组别 | 最终正确 / 20 | 相对 P0 纠错 | 相对 P0 伤害 |
|---|---:|---:|---:|
| P0：共享初始回答 | 14 | — | — |
| D：定向检查 | 13 | 0 | 1 |
| DK：D + 知识 | 14 | 0 | 0 |
| DKB：DK + B 经验 | 14 | 0 | 0 |
| DKC：DK + C 技能 | 13 | 0 | 1 |

DK 比 D 多保住一题，但未超过 P0，不能据此宣称知识库有稳定提升。六道 P0 错题均未纠正。三个改变答案的合法候选全部有害，门控挡住一个、错误接受两个。按预先规定的继续条件，暂不扩展到 60 题。

80 个分支中，18 个结构化输出错误、46 个主动不确定，均回退到 P0；另外 16 个返回合法候选字母。候选缺失率与最终正确率应分别解释。指标报告中 gate 表的 “Error fallbacks” 包含候选错误，不代表发生了 18 次门控调用错误；实际三个门控均无执行或解析错误。

## 实际执行细节

- 选择：种子 20261030，五个官方任务组各四题；按官方分组与题目 ID 排序后抽样，不使用标签。分组依据完整的官方元数据文件。
- P0：`qwen3-vl-plus`，temperature 0.2，top_p 0.95，输出上限 1024；每题最多 12 次工具、16 次模型请求、240 秒，递归上限 40。
- 各分支共享同一 P0 的原始问题/图像/工具证据投影，去除 P0 最终选项及助手诊断断言；每分支最多两次工具、四次模型请求。合法且不同的候选触发一次多模态门控。
- K 使用提供的 V8 知识包（59 张卡片），BM25 + MiniLM 神经稠密检索 + RRF，并检查适用范围。B/C 以训练题干分别重建检索索引。实际 K 注入为 DK 18/20、DKB 17/20、DKC 18/20；B/C 注入分别为 17/20、18/20。
- 八个工具名称见实际配置。总计 413 次中心模型请求、202 次工具尝试；分支收集的 108 条新工具观察尚未独立判定临床增益。
- 逻辑费用增量为人民币 10.753388 元，按既有每百万输入/输出 token 4/12 元的假设计价；不是供应商账单。共享 P0 只计一次。
- 生成全部结束后，独立评分器才读取标签；本次发布导出也在完成后执行，未改动原始预测。

## 代码与复现边界

基线提交为 `2d3e8a0`，V9 实现在 `f2f74e0`；正式生成使用含启动修复的 `8d89a9f`。实现入口：[run_v9_diagnostic.py](../../experiments/run_v9_diagnostic.py)、[v9_retrieval.py](../../experiments/v9_retrieval.py)、[v9_metrics.py](../../experiments/v9_metrics.py)。公开数据由 [export_v9_public.py](../../experiments/export_v9_public.py) 按字段白名单导出。

公开预测和正确性标志足以复核结果计数；公开清单只证明记录的执行结构，无法替代对图像、工具原文的独立临床复核。重新执行模型实验仍需另行提供 V8 知识包、获准使用的原始输入、训练经验池、工具依赖与模型文件、API 凭据；仓库不是包含这些资产的独立运行包。部分检索测试也需要该 V8 知识包。生成前的 38 项离线 V9 测试已通过。
