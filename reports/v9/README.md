## 实际协议和资源

- 固定输入：种子 `20261030`，五个官方任务组各四题，按官方分组/题目 ID 抽样，不用标签选题。本轮为开发诊断。
- 中心模型：`qwen3-vl-plus`，temperature 0.2，top_p 0.95，输出上限 1024，图像 detail auto。
- 共享 P0：每题最多 12 次工具、16 次模型请求、240 秒，递归上限 40。四分支各最多 2 次工具、4 次模型请求；合法且不同的候选触发一次多模态门控。
- 分支共同获得原问题/图像/P0 工具证据投影，去掉 P0 最终选项和助手诊断断言。完整实际消息保留于 `traces/`。
- K：V8 59 张卡片，BM25 + MiniLM 稠密检索 + RRF 与适用范围检查。B/C 按训练题干独立重建索引。K 实际注入 DK 18/20、DKB 17/20、DKC 18/20；B/C 分别注入 17/20、18/20。
- 配置声明八个工具；本轮保存的 202 次工具记录来自六种实际调用工具。工具次数与临床有效证据不等价。
- 总计 413 次中心模型请求、202 次工具尝试，其中分支新增 108 条工具观察；逻辑费用人民币 **10.753388 元**，依据既有每百万输入/输出 token 4/12 元假设计价，非供应商发票。墙钟约 **69.5 分钟**。
- 生成结束后独立评分器读取标签。本次参考选项复用已经完成的独立评分公开映射，同一个 `question_id` 的标签不变；不使用这些标签生成新答案。
