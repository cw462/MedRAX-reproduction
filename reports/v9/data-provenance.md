# V9 资料来源、导出变换与公开范围

本目录用于用户授权的完成后实验复盘。公开病例题干、选项、相关原图、实际模型消息和工具输出，便于历史对照。凭据、API/私钥、模型权重和无关本地文件不在发布范围内。

## 输入与标签

20 题来自固定 `selection.json`，其题干/选项与原图路径是当时输入，而非依据错误重新选择。图像来自 ChestAgentBench 的公开子集，数据集版本 `921e60440927f9893228d843c0206b755744252a`。38 张原图与后来 V10/V11 重叠，复用 [V11 原图](../v11/images/originals)；来源、Eurorad 引用和第三方数据许可限制沿用 [V11 来源说明](../v11/data-provenance.md)。代码许可不重新授权第三方图像或病例内容。

参考答案按 `question_id` 联结已经完成的 [V11 独立评分公开记录](../v11/per-question-outcomes.json)。该输入和 V9 来源同为固定基准标签；V9 当时的独立评分已在生成结束后完成。发布脚本只整理既有记录，没有重新生成答案、重跑评分器或修改终态。

## 可观测记录

从已完成 `runs/v9_diagnostic20/checkpoints` 定向取回 586 个保存文件，选择其中 20 份 P0 checkpoint 和 80 个分支目录归并为 100 个公开 JSON。`terminal` 是当时已保存的终态，`messages` 是当时持久化的模型/工具消息；没有生成未保存的对话或额外模型解释。各分支 `files_present` / `files_absent` 区分实际保存与缺失文件，9 个提前失败的分支没有规划/检索文件。

保留实际 `k_block` / `e_block`、检索排名与相关元数据，读者可据此看到每次到底注入了什么知识/经验。它们为用户提供的 V8 知识资产及训练经验的实验使用记录，不能当作当例患者事实。检索命中不等于指南适用，也不等于工具证据被验证。

## 图像载荷与路径

- `cases/` Markdown 使用共享基准原图；`traces/` JSON 中的图像 URL 替换为实际输入载荷文件，路径均相对于 `reports/v9/`。
- 38 份不同的 data URL 载荷仅做 Base64 解码并保存原字节，没有重新压缩、绘图、裁剪或修复。清单记录实际格式、尺寸与字节数。
- 一部分原消息声明 `data:image/jpeg`，内容实际为 PNG。公开文件扩展名按真实编码选择，并在 [清单](history-manifest.json) 保留当时声明。不能因 MIME 不一致就断言服务端看不到图；本次没有证据证明该问题造成错误。
- 已知原图的私有绝对路径替换为共享图链接；项目内部其他路径替换为 `${PROJECT_ROOT}`，其他私人机器路径省略。消息其余正文、提示词、模型输出及数值保持原样。
- 费用上下文的账号级余额和 reservation ID 不用于解释本实验，导出时省略；逐例请求量、token、原费用汇总和时间保留。没有读取或重新扫描费用账本。

上述图像与模型/工具返回都是证据供复核，而不是新的人工临床标注。参考选项、预测字母和对错已公开，本目录不适合作为盲态推理输入。
